# TP ML — Évaluation de plateaux de Go

## Auteurs
- Mohamed Kraimy
- Bella Taleb El Alem

## Description
Nous avons entraîné un réseau de neurones convolutif (*GoNet*) pour prédire la probabilité de victoire des noirs sur un plateau de Go 8x8.

Nous avons comparé deux fonctions de perte (MSE et BCE) et retenu le modèle entraîné avec la BCE comme modèle final, celui-ci obtenant de meilleures performances sur les données de test.
