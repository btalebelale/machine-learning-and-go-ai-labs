# Machine Learning & Go AI Labs

A collection of machine learning labs and a Go game AI, developed as part of the AI course at ENSEIRB-MATMECA.

## Contents

### TD1 — Introduction to Machine Learning
Foundational ML concepts: data exploration, feature engineering, and first classifiers.

### TD2 — Supervised Learning
Classification and regression on the **Pima Indians Diabetes** dataset.  
Algorithms covered: logistic regression, k-nearest neighbours, decision trees, cross-validation.

### TD3 — Deep Learning & CNNs
Convolutional neural networks for image classification on **MNIST**.

### TD4 — Go Board Evaluation with CNNs (GoNet)
A convolutional neural network trained to predict the probability of Black winning from a given 8×8 Go board position.  
Two loss functions compared — MSE vs BCE — with BCE retained as the final model based on test performance.

### GO Tournament — Go Game Player
A Go player built for a class tournament. Implements a game-playing strategy on top of the provided `Goban` environment.

## Tech Stack

- Python, PyTorch, scikit-learn, NumPy, Matplotlib
- Jupyter Notebooks
